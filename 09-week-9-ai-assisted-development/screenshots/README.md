# Screenshot bukti manual

Simpan screenshot aplikasi pada folder ini setelah menjalankan
`week5_offline_notes` dengan `flutter run -d chrome`. Ambil bukti untuk
query yang cocok, query yang tidak menghasilkan catatan (empty state), dan
query yang dihapus/kosong.

Screenshot hasil query belum disertakan: browser yang sudah terbuka di sesi
kerja ini tidak merespons input dan screenshot yang dihasilkan tidak dapat
disimpan sebagai file melalui sesi tersebut. Jangan gunakan screenshot
placeholder sebagai bukti pengujian.
